# SDKWork Skills Backend SDK Specs

This directory declares `sdkwork-skills-backend-sdk`, the generated and
composed operator family for `sdkwork-skills-backend-api`.

Consumers import `@sdkwork/skills-backend-sdk`. Transport output remains
exclusively under
`sdkwork-skills-backend-sdk-typescript/generated/server-openapi` and is
regenerated from the owner OpenAPI authority.

The family currently exposes 16 owner operations for package, artifact,
category, capability, and marketplace administration.
