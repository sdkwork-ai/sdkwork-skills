# SDKWork Skills HTTP Common Specs

This directory declares the component contract for
`sdkwork-routes-skills-common`.

The crate centralizes Skills HTTP commands, canonical list queries, response
envelopes, error mapping, and calls into the application service. It does not
own surface routes or authentication state.

See [component.spec.json](./component.spec.json) and the canonical
[API standard](../../../sdkwork-specs/API_SPEC.md).
