# SDKWork Skills Standalone Gateway Specs

`component.spec.json` defines the standalone ingress contract. The binary enables the canonical
process-shared database pool before assembly bootstrap, installs one Web Framework pipeline around
the assembly's combined raw business router, and mounts `/healthz`, `/livez`, `/readyz`, and
`/metrics` once at the process boundary. Dependency readiness details are logged server-side and
the HTTP response remains sanitized.
